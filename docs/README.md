# Dokumentasi Kost Pak Sapriadi

Dokumentasi instalasi ada di [INSTALLATION.md](INSTALLATION.md), sedangkan endpoint, autentikasi, role, dan format respons API dijelaskan di [API.md](API.md). Matriks pemeriksaan fitur tersedia di [test-matrix.md](test-matrix.md).

Aplikasi menggunakan PHP 8.4+, MySQL/MariaDB, PDO, dan JavaScript ES modules. Halaman aplikasi dirutekan melalui `index.php?page=...`; API tersedia di direktori `api/`.
